# Web Security Toolkit

Comprehensive, live-working web security toolkit for vulnerability analysis, payload generation, and security testing.

## Features
- HTTP Header Analyzer
- JWT Decoder & Vulnerability Checker
- Payload Generator (XSS, SQLi, Command Injection)
- Multi-format Encoder/Decoder
- CORS Policy Tester
- Vulnerability Pattern Scanner
- Hash Analyzer

## Getting Started
```bash
git clone https://github.com/harinish45/web-security.git
cd web-security
npm install
npm run dev
```
